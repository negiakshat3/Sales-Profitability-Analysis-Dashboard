# Sales & Profitability Analysis Dashboard

This project focuses on analyzing sales and profitability data using Microsoft Excel. I used Microsoft's Financial Sample dataset to explore business performance across different countries, products, customer segments, and discount bands.

### What I worked on
- Created PivotTables to summarize and analyze the data.
- Analyzed key performance indicators (KPIs), including total sales, total profit, profit margin, and units sold.
- Built an interactive-style dashboard with seven charts to visualize sales and profitability trends.
- Compared country, product, discount band, and yearly performance.
- Identified key findings to better understand business performance and profitability.

### Tools Used
- Microsoft Excel
- PivotTables
- Charts and data visualization
- KPI analysis

### Objective
The goal of this project was to practice data analysis, identify meaningful patterns in business data, and present the findings in a clear, easy-to-understand dashboard.

### Dataset
Microsoft Financial Sample dataset.

This was a self-directed portfolio project created to strengthen my Excel and data analysis skills.
